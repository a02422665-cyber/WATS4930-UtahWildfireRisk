# WATS4930 Utah Wildfire Risk Final Project
#### This project displays areas that are higher at risk for wildfires in Utah.
#### This was able to be displayed through various different aspects, such as slope, proximity to urban areas, and landcover.
#### Every dataset was then converted into a "binary layer" displaying which areas were safe and which were not safe.
#### Finally, these layers were all combined to help visualize which areas in Utah are most susceptible to wildfires.
